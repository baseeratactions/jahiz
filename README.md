# جاهز للمعاملات · Jahiz for Transactions

نسخة من موقع بصيرة باسم «جاهز» (أُنشئت 2026-10-18).

- الموقع: https://baseeratactions.github.io/jahiz/
- حسابي (بوابة العميل): https://baseeratactions.github.io/jahiz/portal.html
- لوحة الإدارة: https://baseeratactions.github.io/jahiz/crm.html
- الخادم: `server/Code.gs` (Google Apps Script). الموقع يعمل حالياً على خادم بصيرة نفسه (رابط API في `assets/config.js`)، فطلبات جاهز وعملاؤها تُحفظ مع بيانات بصيرة إلى أن يُنشأ خادم مستقل لجاهز.
- الأسعار والخدمات: `assets/data.js`، ووصف الخدمات: `assets/details.js`.
